#+title: port

Port tracking for ~/.emacs.d/my/calc → maf, one feature at a time.
Legacy bindings in parens are reference only; maf rebinds at port time.
Ported or superseded features are summarized at the end of each section.
Statuses verified against the code 2026-08-12.

* flagged
Present in my/calc but missing from the previous inventory:
- index.el enabled show-point-mode in calc buffers — config, never
  listed; decide whether maf wants it or drops it deliberately.
- The legacy ERT suite (my/calc/tests/, run-tests) was never listed.
  maf's step tests supersede the convention, but the coverage itself has
  no ported counterpart (cleanup: "generate tests full coverage").
- calc-edit-mode-map M-w (my/lisp-kill-ring-save-dwim) — an edit-buffer
  copy convenience, subsumed by maf-edit replacing calc-edit but never
  spelled out.
Looked missing but are not: sum-to-list / list-to-sum and change-sign
are the guts of listed items (poly term ordering; contextual negate).
