Algebra
  Square of binomial sum ......................... (a + b)^2 = a^2 + 2 a b + b^2
  Square of binomial difference .................. (a - b)^2 = a^2 - 2 a b + b^2
  Difference of squares .......................... a^2 - b^2 = (a + b) (a - b)
  Factoring a trinomial .......................... x^2 + (a + b) x + a b = (x + a) (x + b)
  Sum of cubes identity .......................... a^3 + b^3 = (a + b) (a^2 - a b + b^2)
  Difference of cubes identity ................... a^3 - b^3 = (a - b) (a^2 + a b + b^2)
  Log change of base formula ..................... log(x, b) = log(x, k) / log(b, k)
  Standard form of reciprocal function ........... y = a / (x - h) + k
  Exponential growth ............................. f(x) = a b^x
  Binomial sign flip rule ........................ (k - x)^2 = (x - k)^2

Algebra — Absolute value
  Absolute value as a root ....................... abs(x) = sqrt(x^2)
  Absolute value is nonnegative .................. abs(x) >= 0
  Absolute value of a negative ................... abs(-x) = abs(x)
  Absolute value of a product .................... abs(a b) = abs(a) abs(b)
  Absolute value of a quotient ................... abs(a / b) = abs(a) / abs(b)
  Triangle inequality ............................ abs(a + b) <= abs(a) + abs(b)
  Reverse triangle inequality .................... abs(abs(a) - abs(b)) <= abs(a - b)
  Absolute value equation ........................ x = a || x = -a
  Absolute value less than ....................... -a < x && x < a
  Absolute value greater than .................... x < -a || x > a
  Distance between two numbers ................... abs(x - y) = abs(y - x)

Algebra — Combinatorics
  Permutations ................................... P = n! / (n - r)!
  Combinations ................................... C = n! / (r! (n - r)!)

Algebra — Exponents
  Zero exponent .................................. x^0 = 1
  First power .................................... x^1 = x
  Negative exponent .............................. x^(-n) = 1 / x^n
  Product of powers .............................. x^m x^n = x^(m + n)
  Quotient of powers ............................. x^m / x^n = x^(m - n)
  Power of a power ............................... (x^m)^n = x^(m n)
  Power of a product ............................. (x y)^n = x^n y^n
  Power of a quotient ............................ (x / y)^n = x^n / y^n
  Rational exponent .............................. x^(m / n) = (x^(1 / n))^m
  Reciprocal of negative exponent rule ........... 1 / x^(-n) = x^n

Algebra — Fractions
  Addition of fractions .......................... a / b + c / d = (a d + b c) / (b d)
  Subtraction of fractions ....................... a / b - c / d = (a d - b c) / (b d)
  Common denominator ............................. a / c + b / c = (a + b) / c
  Multiplication of fractions .................... (a / b) (c / d) = a c / (b d)
  Division of fractions .......................... a / b / (c / d) = a d / (b c)
  Cancel a common factor ......................... a c / (b c) = a / b
  Cross multiplication ........................... a d = b c
  Reciprocal of a fraction ....................... 1 / (a / b) = b / a
  Sign of a fraction ............................. -(a / b) = -a / b

Algebra — Linear equations
  Linear equation standard form .................. a x + b y = c
  Linear equation slope intercept form ........... y = m x + b
  Linear equation point slope form ............... y - y1 = m*(x - x1)
  Slope formula .................................. m = (y2 - y1) / (x2 - x1)
  Midpoint formula ............................... M = [(x1 + x2) / 2, (y1 + y2) / 2]

Algebra — Logarithms
  Logarithm of a product ......................... log(x y, b) = log(x, b) + log(y, b)
  Logarithm of a quotient ........................ log(x / y, b) = log(x, b) - log(y, b)
  Logarithm of a power ........................... log(x^p, b) = p log(x, b)
  Logarithm of a root ............................ log(x^(1 / n), b) = log(x, b) / n
  Logarithm of a reciprocal ...................... log(1 / x, b) = -log(x, b)
  Base raised to a logarithm ..................... b^log(x, b) = x
  Logarithm of a power of the base ............... log(b^x, b) = x
  Change of base ................................. log(x, b) = ln(x) / ln(b)
  Logarithm of one ............................... log(1, b) = 0
  Logarithm of the base .......................... log(b, b) = 1
  Exponential of a natural logarithm ............. exp(ln(x)) = x
  Natural logarithm of an exponential ............ ln(exp(x)) = x

Algebra — Properties of real numbers
  Commutative property of addition ............... a + b = b + a
  Commutative property of multiplication ......... a b = b a
  Associative property of addition ............... a + b + c = a + (b + c)
  Associative property of multiplication ......... (a b) c = a b c
  Distributive property .......................... a*(b + c) = a b + a c
  Distributive property over subtraction ......... a*(b - c) = a b - a c
  Additive identity .............................. a + 0 = a
  Multiplicative identity ........................ a 1 = a
  Additive inverse ............................... a + -a = 0
  Multiplicative inverse ......................... a*(1 / a) = 1
  Multiplication by zero ......................... a 0 = 0
  Zero product property .......................... a = 0 || b = 0
  Addition property of equality .................. a + c = b + c
  Subtraction property of equality ............... a - c = b - c
  Multiplication property of equality ............ a c = b c
  Division property of equality .................. a / c = b / c
  Double negation ................................ --a = a
  Subtraction as addition ........................ a - b = a + -b
  Division as multiplication ..................... a / b = a*(1 / b)
  Sign rule for a product ........................ -a b = a*-b
  Product of two negatives ....................... -a*-b = a b

Algebra — Quadratic equations
  Quadratic formula, first root .................. x = (-b + sqrt(b^2 - 4 a c)) / (2 a)
  Quadratic formula, second root ................. x = (-b - sqrt(b^2 - 4 a c)) / (2 a)
  Discriminant ................................... d = b^2 - 4 a c
  Sum of the roots (Vieta) ....................... r1 + r2 = -b / a
  Product of the roots (Vieta) ................... r1 r2 = c / a
  Factored form of a quadratic ................... a x^2 + b x + c = a*(x - r1) (x - r2)
  Completing the square .......................... a x^2 + b x + c = a*(x + b / (2 a))^2 + (c - b^2 / (4 a))
  Vertex of a parabola ........................... x = -b / (2 a)

Algebra — Radicals
  Square root as an exponent ..................... sqrt(x) = x^(1/2)
  Nth root as an exponent ........................ nroot(x, n) = x^(1 / n)
  Product of radicals ............................ sqrt(x y) = sqrt(x) sqrt(y)
  Quotient of radicals ........................... sqrt(x / y) = sqrt(x) / sqrt(y)
  Root of a square ............................... sqrt(x^2) = abs(x)
  Rationalize a root denominator ................. 1 / sqrt(x) = sqrt(x) / x
  Rationalize by the conjugate ................... 1 / (a + sqrt(b)) = (a - sqrt(b)) / (a^2 - b)

Conic sections — Parabola
  Vertex form of horizontal parabola ............. x = a*(y - k)^2 + h
  Vertex form of vertical parabola ............... y = a*(x - h)^2 + k
  Standard form of horizontal parabola ........... (y - k)^2 = 4 p*(x - h)
  Standard form of horizontal parabola at origin . y^2 = 4 p x
  Standard form of vertical parabola ............. (x - h)^2 = 4 p*(y - k)
  Standard form of vertical parabola at origin ... x^2 = 4 p y
  Focus of horizontal parabola ................... x = h + p
  Axis of symmetry of parabola ................... x = -(b / (2 a))
  Focus of vertical parabola ..................... y = k + p
  Directrix of horizontal parabola ............... x = h - p
  Directrix of vertical parabola ................. y = k - p
  Average of roots ............................... x = (x1 + x2) / 2

Finance
  Compound interest .............................. A = P*(1 + r / n)^(n t)
  Continous compound interest .................... A = P e^(r t)
  Simple compound interest ....................... A = P*(1 + r)^t

Trigonometry
  Pythagorean triple ............................. a^2 + b^2 = c^2
  Law of sines ................................... eq(a / sin(A), b / sin(B), c / sin(C))
  Law of cosines 1 ............................... c^2 = a^2 + b^2 - 2 a b cos(C)
  Law of cosines 2 ............................... cos(C) = (a^2 + b^2 - c^2) / (2 a b)

Trigonometry — Angle sum and difference
  Sine of a sum .................................. sin(a + b) = sin(a) cos(b) + cos(a) sin(b)
  Sine of a difference ........................... sin(a - b) = sin(a) cos(b) - cos(a) sin(b)
  Cosine of a sum ................................ cos(a + b) = cos(a) cos(b) - sin(a) sin(b)
  Cosine of a difference ......................... cos(a - b) = cos(a) cos(b) + sin(a) sin(b)
  Tangent of a sum ............................... tan(a + b) = (tan(a) + tan(b)) / (1 - tan(a) tan(b))
  Tangent of a difference ........................ tan(a - b) = (tan(a) - tan(b)) / (1 + tan(a) tan(b))

Trigonometry — Double angle
  Sine of a double angle ......................... sin(2 x) = 2 sin(x) cos(x)
  Cosine of a double angle ....................... cos(2 x) = cos(x)^2 - sin(x)^2
  Cosine of a double angle, in sine .............. cos(2 x) = 1 - 2 sin(x)^2
  Cosine of a double angle, in cosine ............ cos(2 x) = 2 cos(x)^2 - 1
  Tangent of a double angle ...................... tan(2 x) = 2 tan(x) / (1 - tan(x)^2)

Trigonometry — Even and odd
  Sine is odd .................................... sin(-x) = -sin(x)
  Cosine is even ................................. cos(-x) = cos(x)
  Tangent is odd ................................. tan(-x) = -tan(x)

Trigonometry — Half angle
  Sine of a half angle, squared .................. sin(x / 2)^2 = (1 - cos(x)) / 2
  Cosine of a half angle, squared ................ cos(x / 2)^2 = (1 + cos(x)) / 2
  Tangent of a half angle, squared ............... tan(x / 2)^2 = (1 - cos(x)) / (1 + cos(x))
  Tangent of a half angle ........................ tan(x / 2) = (1 - cos(x)) / sin(x)
  Tangent of a half angle, by sine ............... tan(x / 2) = sin(x) / (1 + cos(x))

Trigonometry — Pythagorean identities
  Pythagorean identity ........................... sin(x)^2 + cos(x)^2 = 1
  Pythagorean identity for tangent ............... 1 + tan(x)^2 = sec(x)^2
  Pythagorean identity for cotangent ............. 1 + cot(x)^2 = csc(x)^2

Trigonometry — Reciprocal and quotient
  Cosecant as a reciprocal ....................... csc(x) = 1 / sin(x)
  Secant as a reciprocal ......................... sec(x) = 1 / cos(x)
  Cotangent as a reciprocal ...................... cot(x) = 1 / tan(x)
  Tangent as a quotient .......................... tan(x) = sin(x) / cos(x)
  Cotangent as a quotient ........................ cot(x) = cos(x) / sin(x)

Trigonometry — Sinusoidal Functions
  Sinusoidal period .............................. T = (1 / B) 2 pi
  Sinusoidal frequency ........................... f = 1 / T

Trigonometry — Triple angle
  Sine of a triple angle ......................... sin(3 x) = 3 sin(x) - 4 sin(x)^3
  Cosine of a triple angle ....................... cos(3 x) = 4 cos(x)^3 - 3 cos(x)
  Tangent of a triple angle ...................... tan(3 x) = (3 tan(x) - tan(x)^3) / (1 - 3 tan(x)^2)
