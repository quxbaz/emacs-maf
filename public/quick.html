Quick intro five minutes, native profile

1. Load it

(add-to-list 'load-path "~/src/emacs-maf")
(require 'maf)
(add-hook 'calc-mode-hook #'maf-mode)

Then M-x calc.

2. The one idea

Everything goes through one gesture: SPC opens the stack as text, you type or change what you like, RET commits. From home that enters a new formula; on an entry it edits that entry. Then a command acts on what point names: at the bottom . line, the top entry; inside a formula, the sub-formula under point, which is highlighted; on an equation, both sides. The result replaces exactly that part, and point stays there.

3. Try this

  1. SPC, type 2 x + 3 = 11, RET
  2. 3 - subtracts 3 from both sides
  3. 2 / divides both sides by 2
  4. U U undoes both, then M-i solves in one key
1:  2 x + 3 = 11
1:  2 x = 8
1:  x = 4
1:  x = 4
  1. SPC, type (x + 1)^2 = 9, RET
  2. C-b, move point onto the ^
  3. a x expands that side only
1:  (x + 1)^2 = 9
1:  (x + 1)^2 = 9
1:  x^2 + 2 x + 1 = 9
