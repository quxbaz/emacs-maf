components

every way the site shows an example, on one scene

A reference for choosing the fitting one. All use the expand scene from scenes.js; the markup under each heading is what produces it.

scene

Animated: the cursor walks to the sub-formula, the keys echo, the result flashes in. Replays from the control above the pane.

<div data-scene="expand"></div>

diff

Before and after side by side. The before pane shows the cursor and highlight; the after pane outlines the part that changed.

<div data-diff="expand"></div>

diff with a caption

The element's own content replaces the keys and command name above the panes.

<div data-diff="expand"><b>x</b> expands only that side</div>
x expands only that side

reveal

The after pane starts empty; the caption is a button that shows the result, and hides it again.

<div data-diff="expand" data-reveal></div>

result

One pane: the stack before, and the produced entry on a last line after =>. No home dot, no highlight.

<div data-diff="expand" data-result></div>

result, revealed

The same, with the result line behind the button.

<div data-diff="expand" data-result data-reveal></div>
