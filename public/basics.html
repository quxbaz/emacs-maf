Basics using commands contextually, with worked examples

Every example below was run in a live Calc buffer with maf's native profile. The left column is what you press, the right column is the stack as it reads after each step. Formulas are entered the way everything is edited: SPC opens the stack as text, you type, and RET commits. From home, SPC opens a fresh entry; on an entry, it opens that entry for editing. The . line at the bottom is home; a command run there acts on the top entry.

The rule

A command acts on whatever point names. At home, the top entry. On an entry's edge, its line number or the end of its line, the whole entry. Inside a formula, the innermost sub-formula under point, which the highlight shows. On an operator glyph, the operation that glyph performs. With a region marked, the run of terms the region covers. The result replaces exactly that, and point stays on it.

Solving an equation

Three ways, from the most manual to the least.

By hand, both sides at once

A typed number followed by an operator applies that operator to the entry at point. Since the entry is an equation, the command runs once per side.

  1. SPC, type 2 x + 3 = 11, RET
  2. 3 - subtracts 3 from both sides
  3. 2 / divides both sides by 2
1:  2 x + 3 = 11
    .
1:  2 x = 8
    .
1:  x = 4
    .

Isolate the sub-expression under point

Move point onto the x and press j j. Whatever point names is brought alone to the left side. Point on 11 instead would give 11 = 2 x + 3.

  1. SPC, type 2 x + 3 = 11, RET
  2. C-b then move point onto x
  3. j j isolates it
1:  2 x + 3 = 11
    .
1:  2 x + 3 = 11
1:  x = 4

One key from home

M-i solves the top entry for its variable. Press it again on an equation with several variables to cycle through them.

  1. SPC, type 2 x + 3 = 11, RET
  2. M-i
1:  2 x + 3 = 11
    .
1:  x = 4
    .

Acting on one part of a formula

Expand only the side under point

With point on the ^ of the power, the target is that power, and a x expands it in place. The right side is untouched.

  1. SPC, type (x + 1)^2 = 9, RET
  2. move point onto the ^
  3. a x expands
1:  (x + 1)^2 = 9
1:  (x + 1)^2 = 9
1:  x^2 + 2 x + 1 = 9

Factor a run of terms with a region

Mark 2 x + 4 as a region, which Calc has no node for, and press l F to pull out the greatest common divisor. The y outside the region is left alone.

  1. SPC, type 2 x + 4 + y, RET
  2. mark from 2 to 4 with C-SPC and motion
  3. l F factors by the gcd
1:  2 x + 4 + y
1:  2 x + 4 + y
1:  2 (x + 2) + y

Replace a number in place

Typing a number while point is on a numeric leaf replaces that leaf when you press RET. No re-entry of the formula.

  1. SPC, type x + 3 = 11, RET
  2. move point onto the 3
  3. 5 RET
1:  x + 3 = 11
1:  x + 3 = 11
1:  x + 5 = 11

Mapping

The M flag makes the next command run once per element of a vector, or once per side of a relation. Here the square root runs on each element.

  1. SPC, type [1, 4, 9], RET
  2. M Q
1:  [1, 4, 9]
    .
1:  [1, 2, 3]
    .

The I and H flags

Calc's inverse and hyperbolic prefixes route a key to a sibling command, still contextually. I S takes the arcsine of the sub-expression under point; I ^ takes the nth root; H a f factors into factor-and-power pairs. The cheat sheet shows every key's variants on hover.

Editing instead of computing

The same gesture that enters a formula rewrites one. When a change is easier to type than to derive, SPC on the entry opens it as text. Change what you like, press RET, and the entries are re-read. A newline inside an entry splits it in two; joining two lines merges them. Inside the session a run of letters reads as separate factors, so 2xy is 2 x y, and {cm} keeps a multi-letter name whole.

Seeing what you have

  • The highlight under point shows the target before you press anything.
  • The preview panel shows the entry at point in Calc's two-dimensional display.
  • M-h opens the history: every past stack state beside the log that produced it.
  • l b lists every key with its description, most with a worked example; ? shows all of Calc's settings.
  • g l plots the entry at point below the stack.
