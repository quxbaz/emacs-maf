maf an extension to emacs calc

Calc is exceptionally powerful and flexible, but can also feel clunky. maf streamlines Calc’s interactive model and adds substantial features.

Commands are contextual.

The same command with the cursor in two different places.

Square one expression. Cursor on the +, only the highlighted expression is squared.

Square both sides. Cursor on the =, both sides of the equation are squared.

More

Direct stack editing, embedded plots, persistent sessions, formula previews, stack history, and more.

Features

Work on a formula, see the result, keep going.

Contextual commands

Edit right where you are.

Move the cursor to an expression, then run a command. The highlight shows what it will change; the result goes back in the same place.

In an equation, put the cursor on = to apply a command to both sides.

Direct stack editing

Enter math as text.

Press SPC to edit the stack. Change an existing formula or add a new line for a new entry, then press RET to apply your changes.

Type 3xy^2 for 3 × x × y². Braces keep a name together: {cm}.

Embedded plots

See the shape of your result.

Press g l to plot the formula under the cursor, right below the stack.

You can also open it in Desmos with g o, or an interactive gnuplot window with g g.

Tools for everyday work

Read, reuse and revisit your calculations. The links below open screenshots.

Formula previews

See fractions and powers in a panel that follows the cursor. Paper-style output keeps polynomials ordered and simplifies exponential and logarithm notation.

Formula library

s o opens a searchable collection of identities and geometry formulas. Preview one and its variables, then press RET to add it to the stack.

Stack history

M-h shows the commands that changed the stack. Choose a step to see the stack as it was then.

Saved sessions

Enable persistence to restore your stack next time. Preview, restore, rename or delete saved stacks from one menu.

Key binding help

l b lists your active bindings by task, with command descriptions and examples.

Settings and modules

? shows Calc’s settings and their current values. m c opens the module menu to toggle features and choose a key binding profile.
