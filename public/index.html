maf

An alternative UX over Emacs Calc. One key does the right thing wherever point is: on the home line, on a stack entry, on a sub-expression, on a calc selection, on one side of an equation, or on a region of a sum. The result goes back where it came from, and point stays put.

What "contextual" means

A stock Calc command takes its operand from the top of the stack. A maf command first resolves point and the calc state into a target, runs its body on exactly that, then commits the result to the same place. The six targets, in priority order:

TargetWhen it firesOperates on
regionAn active region inside one entryThe run of terms it covers in a + or * chain
selectionA calc selection existsThe selected sub-formula
homePoint is on the . lineThe top stack entry
subexprPoint is inside a formulaThe sub-formula under point
equationPoint is on a relationEach side, the body running once per side
entryPoint is on an entry's edgeThe whole formula

So with x^2 + 2 x + 1 = 4 on the stack, pressing a f with point on the left side factors that side in place. Press it at home and the whole entry is factored. The cheat sheet marks the contextual commands with a dot.

Flags

Calc's I and H prefixes route each command to a sibling, so I S takes the arcsine of the resolved sub-expression rather than of the stack top. maf adds a third flag, M: the next command maps over its subject, once per element of a vector or once per side of a relation, with M r and M c choosing rows or columns of a matrix. Every command's variants are listed in the cheat sheet's hover.

Major features

Targeting, everywhere

Around 220 contextual commands cover arithmetic, algebra, solving, calculus, trig, vectors and sets, statistics, binary and finance, and dates. Each one's targeting policy is a variable you can retune.

Live highlight of the target

The innermost sub-formula under point is highlighted as you move, so you see what a command will act on before you press it.

Regions over chains

Calc has no node for b + c inside a + b + c + d. maf carves the run out, rewrites it, and splices it back, leaving the other terms' text untouched.

Edit the stack as text

SPC turns the stack into an editable buffer, wdired style. Newlines split and join entries. A handwriting dialect reads 2xy as 2 x y, and a layer of in-entry shortcuts wraps, retypes, and duplicates groups.

The map flag and combinators

M maps any contextual command over a vector or an equation. Fold, accumulate, apply, outer and inner products read their operation from the next key, looked up among maf's own commands.

Three key profiles

calc keeps Calc's layout and swaps in maf's commands. native is maf's own layout, the default. vim puts it under h j k l motions. Your own bindings sit above and are never rewritten.

Discoverability built in

l b lists every bound command with a proper name and a worked example. ? shows all of Calc's settings in one readable table. m c is the module menu. s o opens a formula library.

History and persistence

M-h browses every past stack state beside the log that produced it, and pushes any old entry back. An opt-in module restores the stack across Emacs sessions.

Previews and typesetting

A panel follows point showing the entry in Calc's two-dimensional display. With RaTeX installed, G typesets the entry as an SVG, units upright and all.

Plotting three ways

g l embeds a gnuplot SVG themed from your faces, g o opens the formula in Desmos in the browser, g g opens interactive gnuplot. H first plots the whole stack.

Paper-style output

Toggleable rewrite modules keep polynomials in descending order, write exp(x) as e^x, and add the general-base log identities Calc lacks.

Upstream fixes included

Two Calc selection bugs are fixed on the way through: dropped denominator parens in selected compositions, and the selection cache matching the wrong one of two identical entries.

Modules

Each feature beyond the command set is a module, a global minor mode you can turn on or off from the m c menu or through the maf-modules variable. Everything below is on by default except where marked.

Where things stand

maf is under active development and the API is unstable. The version is 0.1.0. The test suite is a set of step tests run against a live Emacs, one file per feature, all expected to pass on main. The additions and changes pages are generated from the commit history, with each commit's recorded reasoning.
