Install and use

maf is a single package with everything it needs in the repository. It requires Emacs 28.1 or later and nothing else. A few modules use optional external programs, listed below.

Get the code

With Emacs 29 or later, the package manager can install straight from the repository:

M-x package-vc-install RET https://github.com/quxbaz/emacs-maf RET

Or clone it and add the directory to your load path. maf's entry file adds its own subdirectories.

git clone https://github.com/quxbaz/emacs-maf ~/src/emacs-maf
(add-to-list 'load-path "~/src/emacs-maf")
(require 'maf)
;; Turn maf on in every calc buffer. Hooking calc-mode rather than
;; enabling once keeps it on across calc-reset, which re-runs the mode.
(add-hook 'calc-mode-hook #'maf-mode)

With use-package on Emacs 30:

(use-package maf
  :vc (:url "https://github.com/quxbaz/emacs-maf")
  :hook (calc-mode . maf-mode))

Then open Calc as usual with M-x calc, or use maf-calc, which opens it full-screen from a special buffer and splits right from a single window.

Pick a key profile

The default profile is native, maf's own layout. Set the variable before loading, or switch live:

(setq maf-bindings-profile 'vim)      ; calc, native, or vim
M-x maf-bindings-set-profile          ; switch in a running session

Your own bindings go in maf-common-user-map or a per-profile user map. maf composes its defaults beneath them and never rewrites them. Whatever is on, m c always opens the module menu. The cheat sheet shows every profile.

Turn modules on and off

The maf-modules variable lists the modules that start on. Two are off by default: maf-persist, because it writes files, and maf-pretty, because it needs an external program.

(with-eval-after-load 'maf
  (add-to-list 'maf-modules 'maf-persist t)
  (maf-modules-apply))

In a session, m c opens a menu where each module can be toggled and its options read.

Try it

  1. Open Calc, press SPC, type x^2 + 2 x + 1 = 4, and press RET.
  2. Press C-b to step back into the entry, move onto the left side, and press a f. That side factors in place.
  3. Press j j anywhere on the entry to isolate x.
  4. Press l b to see every key with an example, or ? for Calc's settings.
