Get started

maf is a single package with everything it needs in the repository. It requires Emacs 28.1 or later and nothing else. Two modules can use external programs, all optional: maf-pretty needs RaTeX for typesetting, and maf-plot uses gnuplot and a browser for plotting. The preview panel can use the posframe package. Everything else works without them.

Get the code

Choose one installation method.

With Emacs’s package manager

On Emacs 29 or later, install straight from the repository:

M-x package-vc-install RET https://github.com/quxbaz/emacs-maf RET

From a local clone

Clone the repository, then add its directory to your Emacs configuration. maf's entry file adds its own subdirectories.

git clone https://github.com/quxbaz/emacs-maf ~/src/emacs-maf
(add-to-list 'load-path "~/src/emacs-maf")

With use-package

On Emacs 30, this installs and enables maf:

(use-package maf
  :vc (:url "https://github.com/quxbaz/emacs-maf")
  :hook (calc-mode . maf-mode))

Enable maf

If you used the package manager or a local clone, add this to your Emacs configuration and evaluate it:

(require 'maf)
;; Keep maf enabled when Calc resets and re-runs its mode.
(add-hook 'calc-mode-hook #'maf-mode)

Then open Calc as usual with M-x calc, or use maf-calc, which opens it full-screen from a special buffer and splits right from a single window.

Pick a key profile

The default profile is native, maf's own layout. Set the variable before loading, or switch live:

(setq maf-bindings-profile 'vim)      ; calc, native, or vim
M-x maf-bindings-set-profile          ; switch in a running session

Your own bindings go in maf-common-user-map or a per-profile user map. maf composes its defaults beneath them and never rewrites them. Whatever is on, m c always opens the module menu. The cheat sheet shows every profile.

Turn modules on and off

The maf-modules variable lists the modules that start on. Two are off by default: maf-persist, because it writes files, and maf-pretty, because it needs an external program.

(with-eval-after-load 'maf
  (add-to-list 'maf-modules 'maf-persist t)
  (maf-modules-apply))

In a session, m c opens a menu where each module can be toggled and its options read.

Dependencies

WhatRequired?Needed byNotes
Emacs 28.1+requiredeverythingCalc and the other libraries maf uses are built in. This is the only requirement.
posframeoptionalmaf-previewGives the preview panel a child frame on graphical displays. Without it, or on a terminal, the panel is drawn inside the window.
RaTeX render-svgoptionalmaf-pretty, which is off by defaultA LaTeX math renderer in Rust. Without it, the preview panel still shows the entry in Calc's Big display. Download a prebuilt CLI archive from the RaTeX releases page, for example ratex-cli-v0.1.14-x86_64-unknown-linux-musl, and unpack it; the binaries bundle the KaTeX fonts. Put render-svg on your exec path or in ~/pkgs/ratex, where maf-pretty-program looks by default, or point that variable at it. Needs a graphical Emacs with SVG support.
gnuplotoptionalmaf-plot, g l and g gFor the embedded SVG plot and the interactive plot window. Without it those two keys report that gnuplot is missing; the Desmos plot still works. maf-plot-gnuplot-program.
A browseroptionalmaf-plot, g oFor the Desmos plot only. Auto-detected; override with maf-plot-browser.
