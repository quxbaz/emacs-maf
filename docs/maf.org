** text
   maf works on top of calc as a set of optional features. features can be
   toggled on or off tailored to your preferences
** major features
   - contextualized commands (including region context)
   - selection replacement, direct commands on subexpression
   - passive subexpression highlighting
   - direct stack editing instead of separate buffer
   - embedded graphs
   - history to replace trail
   - session persist
** minor features
   - latex rendering
   - editing shortcuts
   - rewrite rules
   - formulas
   - options
